StatAtlas Japan — an independent national statistics site for Japan that runs entirely from its own files, with no network request. Seven sections (Overview, Population, Economy, Society, Regions, Data explorer, About) covering population, GDP, jobs, prices, trade, energy, schools, health and housing, with every figure carrying its source and year. Charts are hand-drawn SVG (population trend, GDP, unemployment, inflation, age pyramid, age structure, energy mix, PISA scores, prefecture bars); the Regions page has a searchable, filterable, sortable prefecture table, and the Data explorer searches and sorts 36 indicators and downloads them as CSV. Responsive layout, desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser (or at a phone size). To hand the entry in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
